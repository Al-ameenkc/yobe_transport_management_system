Figure 3.12: Flowchart for Seat Hold Algorithm

START
Input: schedule_id, seat_ids[], user_id
Call expire_stale_holds() to release expired holds
Count seats where status = 'available'
Count equals requested seats?
No → Raise error: seats not available
Set hold_expires_at = NOW() + 10 minutes
For each seat: UPDATE status='held', held_by=user_id
All updates successful?
No → Roll back and return failure
Return hold_id and expires_at to client
END
