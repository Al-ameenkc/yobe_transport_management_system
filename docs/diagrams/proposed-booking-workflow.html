Figure 3.6: Proposed Online Booking Workflow

Passenger accesses web application
Search route, date, and destination (within or outside Yobe)
View available schedules and vehicle types
Select trip and open interactive seat map
System holds selected seats in real time
Passenger enters details and proceeds to checkout
Payment processed via Paystack or mock gateway
Booking confirmed; e-ticket and QR code generated
Ticket sent by email/SMS; passenger views booking history
Admin verifies ticket at boarding using QR scanner
Trip completed; records stored in database

Automated digital workflow replacing manual paper-based booking in the proposed system
