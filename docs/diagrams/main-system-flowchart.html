Figure 3.11: Main System Flowchart for Online Booking

START
Passenger opens web application
Enter origin, destination, and travel date
System retrieves matching schedules and fares
Schedule found?
No → Display "No trips available" and END
Passenger selects schedule and opens seat map
System displays available seats in real time
User authenticated?
No → Redirect to login/register
Hold selected seats for limited time
Seats held successfully?
No → Show error and return to seat map
Passenger enters phone and proceeds to checkout
Process payment (Paystack / offline / mock)
Payment successful?
No → Release hold and show payment failure
Confirm booking, generate ticket and QR code
Send email/SMS notification to passenger
END

High-level flowchart for the proposed online booking process
